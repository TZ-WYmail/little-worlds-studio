# Little Worlds Studio 🌱

**Crafting Tiny Worlds, One Scene at a Time.**

Little Worlds Studio is an independent creative studio focused on building beautiful, healing miniature 3D worlds with native Three.js and JavaScript.

We explore the intersection of 3D art, procedural modeling, interactive web experiences, and AI-assisted creative development.

Our goal is to transform carefully crafted miniature environments into reusable, interactive, and production-ready web experiences.

## 🎨 Art Direction

Our visual identity is inspired by:

- Cozy miniature dioramas
- Healing and peaceful environments
- Handcrafted architectural models
- Soft pastel color palettes
- Natural materials and gentle lighting
- Subtle environmental animations

We prioritize visual quality, artistic consistency, and thoughtful details over excessive visual effects.

## 🛠 Technology

- Three.js
- Native JavaScript (ES Modules)
- WebGL
- GLSL Shaders
- Vite
- Blender (for selected 3D assets)
- AI-assisted modeling and creative workflows

## 本地 3D 研发流程

每个商品在 `projects/` 下维护自己的候选版本和验收。总仓库工作流提供从反馈、同镜头复拍、回归检查到手机交付的步骤，并附每轮记录模板。[研发与迭代工作流](WORKFLOW.md) · [蓝花楹书店复盘](projects/jacaranda-bookshop/docs/ITERATIONS.md)

从本仓库打开 Codex，使用微缩美术与 Three.js 工程技能开始打样，再按需调用场景、几何、材质、灯光、着色器和测试技能。当前基础工具为 Node.js、npm 和浏览器。[项目技能](.agents/skills/)

六个社区技能来自 [cesartevisual/threejs-skills 固定快照](https://github.com/cesartevisual/threejs-skills/tree/84f9bcb4bea1f7a28d57fe7f0af78f7f9c3dc467)，许可见 [MIT LICENSE](.agents/skills/THREEJS-SKILLS-LICENSE)。

## ✨ Design Principles

- Visual quality comes first.
- Every object should have a clear artistic purpose.
- Animations should feel natural and subtle.
- Scenes should be modular and reusable.
- Performance and maintainability matter.
- Every scene should be suitable for real web projects.

## 🎯 Long-term Vision

To build a collection of premium, reusable 3D scene templates, interactive components, visual effects, and creative web assets for frontend developers and UI designers.
