# 工程结构

| 位置 | 职责 |
| --- | --- |
| `src/index.js` | 公开嵌入接口、独立蓝花楹模型和模型资源释放 |
| `src/main.js` | Demo 挂载及失败提示 |
| `src/core/` | 组装场景、正交取景、OrbitControls、暮色天幕、天光和夕照、渲染与生命周期 |
| `src/config/sceneConfig.js` | 默认镜头、书店尺寸、树位和形态 |
| `src/world/` | 独立模型的摆放、底座、接触阴影、局部灯光效果、天气粒子和建模工具 |
| `src/assets/` | 书店、室内、树木、地面与街角道具 |
| `src/materials/` | 公共材质与程序化微纹理 |
| `src/utils/` | 种子随机数及资源释放 |

世界坐标采用 Y 向上，正门沿本地 +Z。底座约为 14 × 10 单位。树模型的局部原点在树干接触地面处。窗户下层留有真实开口，玻璃使用低不透明度的独立薄片。

树干、根、主枝和枝梢使用渐细曲线管合并为一个几何体。每棵树的叶片和花朵分别由实例网格批量绘制，屋瓦、书脊、路砖和落花也使用实例化。相机控制在交互时重绘。开启环境动效时，仅在标签页可见且画布进入视野时驱动动画帧，静态阴影沿用缓存。每次挂载创建独立材质、纹理及几何体。释放过程断开尺寸观察并回收实例、纹理、几何材质、阴影图和渲染器。

暮色天幕用程序化着色器绘制远霞和薄云。夕照与冷色环境光负责建筑和树冠的体积。带阴影的街灯照亮下方路面，橱窗光与玻璃反光独立调节。窗格投影使用静态渐变遮罩模拟。

天气过渡同时控制远霞、移动云带、场景雾、室内外用光、石板材质和三维粒子。花瓣、雨线和水纹把时间传给着色器，避免逐帧重建几何体。背面有单独的后门、侧窗和排水构件模块。

天气与时刻独立插值。路灯通过投影光、灯罩亮度、相机朝向光晕和受湿度影响的局部光束表现柔和明暗变化。

深夜把大面积补光压低，由店内透光和街灯维持可读性。右侧橱窗的聚光会穿过窗框，使用几何投影形成窗框和近处道具的阴影。春雨时湿石板使用 512×384 平面反射贴图，按视角采样实景，然后用石板接缝、粗糙度遮罩和水纹打散反射。雨滴使用实例几何，并按位置响应橱窗与街灯附近的暖光。

一楼两扇橱窗、正门玻璃、两侧窗和后门窗对应真实墙体开口。灯具全部置于店内，外射光由墙体、窗框和家具遮挡，柔和补光保持在室内尺寸内。白昼把人工光、玻璃和灯罩发光、光晕及雨滴的暖光响应统一归零。窗灯和街灯使用可在上下文恢复时重建的静态阴影缓存。
